## Car Rental System

A car rental management system developed in C as a first-year project at EMSI.

📌 About the Project

This project is a simple car rental management system that allows users to manage vehicles and clients through a menu-driven program.

🚗 Vehicle Management

- Add vehicles
- Display vehicles
- Modify vehicle information
- Delete vehicles

👤 Client Management

- Add clients
- Modify client information
- Delete clients

📚 Concepts Used

- Structures
- Arrays of structures
- Functions
- Character strings
- strcmp()
- Loops
- Conditions
- switch
- Searching
- Adding, modifying and deleting data
- Menu-driven programming

🛠️ Technologies

- C
- GCC
- Visual Studio Code
  
🎯 Objective

The objective of this project was to apply the C programming concepts learned during my first year and develop a complete program based on a real-world use case.
